# KeyGraph

Локальное приложение для хранения паролей и просмотра связей между аккаунтами.

## Скачать для Android

[Скачать KeyGraph 0.2.7 (APK)](https://raw.githubusercontent.com/FireAspec/KeyGraph-APK/main/KeyGraph.apk)

В версии 0.2.7 исправлено переключение разделов двумя быстрыми свайпами вправо. Для нового хранилища автоматически создаётся код восстановления.

Android устанавливает 0.2.7 отдельно от прежней 0.2.6. Если нужно перенести записи, сохраните зашифрованную копию в старом приложении и откройте её в новом.
